# IamLAMMPS 增量重构计划：面向 ODS-W 研究平台扩展

## Context

Phase 1~4 已全部完成并通过端到端验证（2811 行 src, 1005 行 tests, 18 单元测试 + 5 个 e2e 测试全绿）。用户要求**增量重构**——不重写任何现有代码，仅添加新模块并对现有文件做最小改动（共 ~16 行），将纯 W Agent 扩展为支持 oxide/W 界面研究、HPC 后端、DFT/MLIP 钩子的可扩展平台。

**核心原则**：新代码导入旧代码，旧代码不导入新代码。现有全部 tests/e2e 必须始终通过。

## Phase 1：统一任务/结果模式 (core_types.py)

**新建** `src/lammps_agent/core_types.py` (~60 行)

```python
@dataclass SimulationTask:
    code: str                     # LAMMPS 脚本文本
    backend: str = "local"        # "local" | "slurm"
    resources: dict = field(...)  # {"mpi_np": 4, "timeout": 300}
    metadata: dict = field(...)
    work_dir: Path | None = None

@dataclass SimulationResult:
    success: bool
    outputs: dict = field(...)    # {"stdout_path": ..., "output_files": [...]}
    timing: dict = field(...)     # {"wall_time": 3.2, "timed_out": False}
    errors: list[str] = field(...)
    raw_result: Any = None        # 保留原始 LammpsRunResult
```

**现有文件改动**：无

**新测试**：`tests/test_core_types.py` (~30 行)

```
Phase 5: structures/ + dft/ + mlip/ → tests → 跑全部测试 + e2e 回归
```

每个 Phase 完成后都跑一次完整回归：
```bash
python -m pytest tests/ -v                    # 单元测试
python tests/test_e2e_w_minimize.py            # 基础 e2e
```
